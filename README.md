# AUREVIA — Premium Skincare E-Commerce Platform

A high-end, AI-powered luxury skincare demonstration website featuring cinematic 3D product showcases, Three.js WebGL visualization, liquid-glass interface design, and client-side shopping experiences.

Live demo store featuring four master formulations:
1. **Aurevia Radiance Serum** — Stabilized 15% Vitamin C & 24K gold particulate brightening elixir.
2. **Aurevia Hydration Cream** — Biomimetic triple ceramide & arctic cloudberry barrier cream.
3. **Aurevia Botanical Cleanser** — Gentle ceremonial matcha & chamomile hydro-gel wash.
4. **Aurevia Renewal Oil** — Patagonian rosehip, bakuchiol, and virgin argan midnight treatment.

---

## Features

- **Cinematic 3D WebGL Showcases**: Procedural cosmetic packaging models with glass refraction, studio lighting rigs, ACESFilmic tone mapping, and particle effects.
- **Scroll-Driven Storytelling**: Choreographed camera motions, ingredient breakdowns, and sensory ritual walkthroughs.
- **Liquid-Glass UI**: High-blur translucent surfaces (`backdrop-filter: blur(20px)`), refined bronze/champagne accents, and editorial typography (Italiana + Inter).
- **Client E-Commerce Suite**: Persistent shopping bag (localStorage), real-time free shipping threshold calculator, search and category filters, interactive accordions, and preview checkout.
- **Pure Zero-Dependency Client**: Standard HTML5, CSS3, vanilla ES Modules, and Three.js via CDN importmap. Ready for GitHub Pages deployment with zero build steps.

---

## Deployment to GitHub Pages

1. In your GitHub repository settings, navigate to **Settings** → **Pages**.
2. Under **Build and deployment** → **Branch**, select `main` (or `master`) and folder `/ (root)`.
3. Click **Save**.
4. Your website will be live at `https://<your-username>.github.io/<repository-name>/`.
